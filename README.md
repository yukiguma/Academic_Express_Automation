# Academic Express Auto Answer

Chrome/Edge用のブラウザ拡張機能。Academic Express（英語学習システム）の問題を自動解答します。
複数のサイトに対応しており、ポップアップメニューから対象サイトを動的に登録・管理できます。

## 機能

- ✅ **マルチサイト対応 (New)**: 拡張機能のアイコンをクリックし、任意のAcademic Expressサイトで有効化可能
- ✅ **自動解答**: マッチング、選択問題、穴埋め、並び替え、語彙テスト等に対応
- ✅ **データ永続化 (New)**: 語彙データ等をローカルに保存し、次回の学習に活用
- ✅ **XHRインターセプト**: 問題データをリアルタイムでキャプチャし、正確な解答を生成
- ✅ **速度調整**: 高速モード / 低速モード（人間らしいタイミング）
- ✅ **連続実行**: 自動で次の問題へ進行

## 対応問題タイプ

| タイプ | 対応状況 | 備考 |
|--------|----------|------|
| Matching | ✅ | 画像マッチング等 |
| Insertion | ✅ | 文挿入 |
| Multiple Choice | ✅ | 選択式 |
| True/False | ✅ | 正誤判定 |
| anaumeFilIn (穴埋め) | ✅ | 空所補充 |

## インストール

### Chrome

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を有効化（右上トグル）
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `extension/` フォルダを選択

### Edge

1. `edge://extensions` を開く
2. 「開発者モード」を有効化（左サイドバー）
3. 「展開して読み込み」をクリック
4. `extension/` フォルダを選択

## 使い方

1. 対象の **Academic Express サイト** にアクセスします。
2. ブラウザのツールバーから **拡張機能アイコン** をクリックします。
3. ポップアップメニューの **「このサイトで有効にする」** ボタンをクリックします。
   - 権限のリクエストが表示された場合は許可してください。
   - ページが自動的にリロードされます。
4. 問題ページを開くと、ヘッダーに **「自動入力」** ボタンが表示されます。
5. ボタンをクリックして自動解答を開始します。

### 管理機能 (ポップアップ)

- **有効化/無効化**: サイトごとに拡張機能のON/OFFを切り替えられます。
- **サイト管理**: 有効化したサイトの一覧が表示され、不要なサイトは削除（権限解除）できます。

### 速度モード

- **低速モード**: 読解時間を含む人間らしいタイミング（推定時間表示）
- **高速モード**: 即時解答

## ファイル構成

```
extension/
├── manifest.json   # 拡張機能マニフェスト (Manifest V3)
├── popup.html      # サイト管理用ポップアップUI
├── popup.js        # ポップアップのロジック (権限管理)
├── background.js   # Service Worker
├── content.js      # コンテンツスクリプト (UI・解答ロジック)
├── solvers.js      # 問題タイプ別解答ロジック
├── xhr-intercept.js # XHRデータ取得
└── icons/          # アイコン
```

## 技術詳細

- **Manifest V3**: 最新のChrome拡張機能規格準拠
- **Dynamic User Scripts**: ユーザーの操作に応じて任意のサイトにスクリプトを注入
- **Web Request API**: 問題データの取得と解析
- **Local Storage**: 学習データの永続化
- **AI Development**: Google DeepMindのAIエージェント「Antigravity」により開発・生成
